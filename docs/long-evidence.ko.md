# 긴 근거 분할과 전체 원장 연결 (v0.4)

[English](long-evidence.md) | **한국어**

새 프로파일에서 `inspection.partition_long_evidence: true`를 설정합니다. `plan`은 모델 추론 전에 **실행할 모든 조각**을 기존 Laya 토크나이저·직렬화기로 검사합니다. 모델을 추가 로드하지 않습니다. Jev를 명시적으로 선택한 경우에는 선언된 요청 바이트 한도를 로컬에서 확인하며, API를 호출하거나 Jev 내부 토큰 한도를 검증하는 것은 아닙니다.

## 누락 없는 분할의 의미

행·상위 질문·분석 세트·선언된 행 쌍의 원래 ID를 유지합니다. 한도 안이면 그대로 검사합니다. 한도를 넘으면 원본 JSON의 모든 값을 타입이 있는 경로와 함께 열거합니다. 빈 목록·객체·null도 보존하고, 긴 문자열에는 문자 위치를 붙입니다. 연속 구간을 이분하여 모든 조각이 한도 안에 들게 합니다. `partition-plan.json`에 원본·항목 해시, 구간, 토크나이저 검사를 고정합니다. 검증 시 원본에서 조각을 다시 만들고 누락·중복·순서 변경·값 변경을 거부합니다.

**각 조각에 모든 연산자의 실제 모델 응답**이 있어야 합니다. 조각 판단을 가짜 확률이나 하나의 전체 결론으로 합치지 않습니다. 모든 조각의 판단이 성공해야 원래 검사 단위가 완료됩니다. `partition-coverage.csv`는 원래 단위와 조각 수를 구분하고, `inspection_results.csv`에는 원래 ID·조각 구간·문맥 유형이 기록됩니다.

**모든 조각을 읽은 것과 모든 근거를 한 문맥에서 함께 판단한 것은 다릅니다.** 후보는 검토할 질문 묶음이며, 조각 사이의 모든 고차 상호작용이나 무제한 행 쌍 검사를 완료했다고 주장하지 않습니다. 기존에 선언한 행 쌍 범위는 유지합니다. 행 쌍의 각 조각에는 두 효과의 정규화된 전체 필드를 함께 반복 제공하고, 원문 값과 출처는 조각에 빠짐없이 남깁니다. 이 필수 비교 표나 더 나눌 수 없는 항목 자체가 한도를 넘으면 계획을 명시적으로 실패시킵니다. 원문 확인·독립 이중검토·결과별 RoB·합성 승인은 별도입니다.

기존 실행은 저장된 소스로 재현합니다. 새 방식은 새 실행 폴더에 적용하며, 미완료 실행의 상태만 바꿔 완료로 만들지 않습니다.

## 전체 효과 원장 연결

논문 제목 유사도가 아닌 명시적 효과 ID로 연결합니다. 도우미는 `source_effect_id`, `effect_row_id`, `effect_id` 중 하나와 지원하는 명시적 열 이름을 사용합니다. 비어 있는 값만 채우고, 기존 값과 다르면 충돌로 남깁니다. 원본 입력 셀은 보존하고 계획 시 원장과 해시를 함께 저장합니다.

```bash
python3 -m bio_topics link-ledger \
  --input /absolute/input.csv --profile /absolute/project.json \
  --ledger /absolute/full-effects.csv --out /absolute/new-linked-profile
python3 -m bio_topics plan \
  --input /absolute/input.csv --profile /absolute/new-linked-profile/profile.json \
  --out /absolute/new-run
python3 -m bio_topics run --out /absolute/new-run
python3 -m bio_topics verify --out /absolute/new-run
```

기본값은 **모든 입력 행의 효과 ID가 충돌 없이 연결되어야 통과**합니다. `--allow-unmatched`를 지정하면 미연결 행을 미확인 상태로 보존합니다. 중복 효과 ID는 임의 선택하지 않고 실패합니다. 여러 시트 XLSX는 시트를 지정하고, 수식은 허용하지 않습니다. 해당 원장의 CI 수준이 백분율일 때만 `--ledger-ci-level-percent`를 지정합니다. 다른 입력 파일의 단위를 상속하거나 값의 크기로 추정하지 않습니다.

`ledger-linkage.csv`는 입력 행별 연결·미일치·출처·충돌을 기록합니다. `unused-ledger-entries.csv`는 원장에는 있지만 입력에는 없는 항목이며, **모델 검사 완료로 세지 않습니다.** 전체 원장 자체를 검사하려면 원장을 입력으로 사용하거나 해당 효과 행을 새 입력에 명시적으로 포함해야 합니다. 파일 연결은 원문 검증이나 모집단 독립성 확인이 아닙니다.

연구·모집단·분석·논문 표는 범위를 지정한 `clinical.ledger_files`로 연결할 수 있습니다. 코호트 중복 관계는 근거 수준과 출처를 따로 요구합니다. 논문 단위 정보로 개별 효과의 시점이나 코호트를 추정하지 않습니다. 없는 전체 원장을 그림용 CSV에서 추정으로 복원하지 않습니다.

## 시점 수식어 분리

확인된 정규화 규칙에 `assign`을 넣어 명시적인 `lag`, `exposure_updating`, `exposure_duration`, `exposure_start`, `dose` 수식어를 분리할 수 있습니다. 원문 문자열과 출처를 보존하고, 원장에 다른 값이 있으면 덮어쓰지 않고 충돌로 남깁니다. 상위 시점 표현에서 수식어를 분리하기 위해 별도의 가상 원장을 만들 필요가 없습니다.

## v0.4.1 검사 및 출력 수정

- `inspection.compact_evidence: true`는 복원 가능한 표와 공통 출처 참조로 반복 표현을 줄입니다. 모든 원본 값을 유지하고 복원 일치를 검사합니다. 검사 범위와 질문은 유지하며, 너무 긴 표는 펼친 뒤 분할합니다.
- 시점 검토가 명시적으로 미확정이면 기존 노출 시점 라벨을 미확정으로 바꿉니다. 기존 값과 검토 근거는 출처 기록에 보존하며 새 시점을 추정하지 않습니다.
- ID 연결과 메타데이터 완전성은 별도로 표시합니다. 모집단 설명을 참여자 집단 ID나 독립성 근거로 자동 승격하지 않습니다.
- 임상 모드의 `candidates.csv`는 질문 정보가 갖춰진 묶음, `review_queue.csv`는 불완전한 묶음, `all_candidate_families.csv`는 전체 묶음을 보존합니다. 연결표는 두 목록의 묶음을 모두 연결하고 검사표는 전체 검사를 유지합니다. 질문 정보 완성은 합성 가능성을 보장하지 않습니다.
- 과학적 입력이 바뀌면 새 검사가 필요합니다. 완료 실행은 고정된 코드와 입력을 유지합니다. 이번 버전은 실행 간 모델 응답 자동 재사용을 제공하지 않습니다.

합성 자료 기반 소프트웨어 테스트 69개가 통과했습니다. 과학적 유효성이나 실제 Jev 성능을 검증한 결과는 아닙니다.
