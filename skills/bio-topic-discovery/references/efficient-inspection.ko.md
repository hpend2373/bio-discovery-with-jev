# 근거를 공유하는 전수 검사 기본 설계

[English](efficient-inspection.md) | **한국어**

Bio Discovery with Jev의 새 발견 작업은 이 설계를 기본으로 사용합니다. 사용자 의도와 모든 원본 관측을 보존하면서 같은 근거의 반복 표현과 불필요한 질문을 줄입니다. 로컬 Laya와 명시적으로 선택한 Jev에 적용합니다. 이 지침 자체가 중단된 실행을 재개할 권한을 주지는 않습니다.

## 현재 구현 범위

로컬·배포 스킬은 지금부터 이 설계를 따릅니다. CLI에서 기존 행·셀·쌍 × 연산자 방식의 새 DEG 계획을 만들려면 `plan --legacy-deg`를 명시해야 합니다. 과거 계약을 의도적으로 선택한 경우에만 사용하고 기본 지침을 우회하려고 자동 추가하지 않습니다. 기존 실행의 고정 계약과 메타분석 계획은 유지합니다.

**범용 유전자 카드 실행기, 의존 관계에 따른 실행 간 재사용, 여러 카드의 GPU 배치는 이번 배포에서 완성된 기능이 아니라 구현 요구사항입니다.** 현재 엔진은 한 근거의 질문을 묶고 정확한 요청에 결합된 응답 캐시를 지원합니다. 새 압축 계약은 구현·검증한 뒤 실제 모델 완료를 주장해야 합니다. 기존 조합 확장으로 자동 복귀하지 않습니다. 문서 수정·가역 압축·연결 검증만으로 모델 전수 검사가 끝난 것은 아닙니다.

## 1. 작업을 늘리기 전에 과학적 범위 고정

연구, 비교 방향, 세포, 요청된 모든 시간 비교, 민감도 정의, 환자 가용성과 관계 범주를 기록합니다. 약한 결과·비유의·결측·단일 환자 기술 결과도 유지합니다. 다른 과학 파이프라인이나 편리한 일부 비교로 임의 전환하지 않습니다.

다음 세 목록을 구분합니다.

1. 파일·시트·원본 행·원본 값을 포함한 불변 관측 원장.
2. 근거 카드와 선언된 과학적 질문, 원본 연결표.
3. 모델 요청·선택형 질문·응답 원장. 배경·미확정·실패도 포함.

한 관측은 카드에 한 번 저장하고 여러 질문이 참조할 수 있습니다. 중복 표현 제거와 관측 제거는 다릅니다. 질문을 바꾸면 새 검사 계약이며, 옛 응답의 의미가 자동 보존되는 것은 아닙니다.

## 2. 근거를 공유할 단위

세포 간 DEG 탐색은 **연구 × 유전자**를 기본 카드로 삼고, 해당 유전자의 요청된 모든 세포와 시간 비교를 담습니다. 연구·종·유전자 식별자·비교 방향·환자 맥락을 구분합니다. 식별자 미상 행을 가상의 동일 유전자나 연구로 합치지 않습니다.

주 세포 정의와 민감도 정의는 역할을 표시해 함께 비교합니다. 같은 세포에서 추린 부분집합을 독립 코호트로 세지 않습니다. 같은 내용의 저장 공간은 공유할 수 있지만 중복 원본 행의 ID와 연결은 보존합니다.

메타분석은 **임상 질문 → 호환 가능한 분석 세트**로 묶습니다. 선택한 효과 ID, 척도·추정량·임상 층, 중복 규칙과 미해결 독립성을 유지합니다. 유전자 묶음을 적용하지 않습니다. 논문 수·독립 근거·합성 가능·모델 검사 완료는 별개입니다.

## 3. 사실은 한 번 계산하고 해당되는 과학적 질문만 검사

방향, 환자 수, 환자별 부호, 결측, 수치 무결성, 민감도 차이는 전체 입력에서 한 번 계산합니다. 계산 버전과 기여 행 ID를 보존합니다. 결정론적 검사는 Laya/Jev의 과학적 판단을 대체하지 않습니다.

DEG 카드에서는 보통 다음을 선언합니다.

- 모든 유전자 카드의 통합 검토 1개. 단일 세포만 있거나 미확정인 카드도 포함.
- 원본 관측이 있는 요청 세포 비교 × 시간 비교별 질문. 주 정의와 민감도 근거를 함께 명시하고 주 근거가 없으면 결측으로 표시.
- 사용자 범위에 포함되는 경우 출처·버전이 있는 경로 또는 서로 다른 유전자 사이의 관계 질문.

모든 원본 행·쌍에 일반 연산자 8종을 기계적으로 곱하지 않습니다. 통합 답변·FDR·효과 크기·상위 K개로 나머지 선언된 질문을 검사할지 결정하지 않습니다. 무효·반대 방향도 보존합니다. 요청된 세포·시간의 근거가 없으면 공백과 사유를 기록합니다.

동일 유전자 검사만으로 이종 유전자 면역 신호나 대사 경로를 다룬 것으로 보지 않습니다. 이 범위에는 출처·방향·식별자·근거 연결이 있는 별도 버전 관계 원장을 만들고, 1차 점수 필터 없이 선언된 적격 관계를 모두 검사합니다. 주석 부족은 미확정입니다. 동일 유전자 카드만으로 경로 전수를 주장하지 않습니다.

## 4. 가역 압축과 요청 내부의 완전한 근거

반복 스키마·파일 맥락·상수는 카드 안에서 한 번 저장합니다. 해독 규칙이 있는 정확한 표·사전을 사용하고 없는 키·null·빈 문자열·0을 구분합니다. 원문·수치 정밀도·정규화 값·충돌 검토를 보존합니다. 추론 전에 모든 관측을 복원해 원본 값·ID·연결 중복도를 전 행 대조합니다.

각 요청 안에 질문에 필요한 근거와 정의가 있어야 합니다. 실제 내용이 없는 외부 ID만 보내면 안 됩니다. 공유 표현은 해당 요청 안에서 복원 가능해야 합니다. 손실 요약을 전수 근거라고 부르지 않습니다.

실제 배포 토크나이저로 근거·질문·선택지 전체 길이를 확인합니다. 긴 카드는 선언한 과학적 경계로 나누고 모든 행·질문 배정을 유지하며 필요한 통합 검토를 추가합니다. 조각 완료는 전체 공동 판단이 아닙니다. 통합 근거가 들어가지 않거나 통합 실행기가 없으면 전역 질문은 미완료입니다. 행·질문 자르기나 조용한 누락을 금지합니다.

## 5. 완전히 같은 판단만 재사용

캐시는 근거 전체·질문·선택지·과학적 계약·직렬화/계산 버전·제공자·모델 리비전·토크나이저·추론 설정·전송 구성을 결합합니다. 유전자 이름·후보 제목·행 ID가 같다는 것만으로 재사용하지 않습니다.

원본 변경 → 영향 카드 → 질문 → 관계/통합 → 후보의 의존 연결을 둡니다. 영향받는 항목은 재계산하고 독립적인 성공 판단은 전체 조건이 같을 때만 재사용합니다. 옛 연산자 응답을 새 통합 질문의 답으로 바꾸지 않습니다. 배치 크기나 동료 카드가 수치 결과에 영향을 주는 실행 방식이면 이 맥락도 캐시 식별자에 포함하고, 같은 배치의 변경 없는 카드도 재실행 대상이 될 수 있음을 밝힙니다.

원시 응답과 체크포인트를 보존합니다. 원인을 해결한 실패만 재시도하고 영구 실패는 미완료로 둡니다. 반복되는 전체 시스템 오류는 모든 항목을 실패로 채우기 전에 중단·점검합니다.

## 6. 배치와 시간 예측

백엔드가 지원하면 질문 정의·토큰 예산이 맞는 카드를 묶습니다. 요청 순서·카드 ID·질문 ID·개별 성공을 보존하고 반환 수·모델·선택지·토큰 사용을 검증합니다. 배치를 맞추려고 해당되지 않는 질문을 채워 넣지 않습니다. HTTP 요청 감소만으로 GPU 계산 감소를 주장하지 않습니다.

장기 실행 전 짧고 긴 카드·결측·반대 방향·기술 결과를 포함한 진단 표본에서 단일/배치 결과를 비교합니다. 이 표본은 전송·품질·시간 확인용이며 전수 목록을 대체하지 않습니다. 선택 일치율과 수치 차이를 보고하되 과학적 동등성으로 해석하지 않습니다.

전체 길이·질문 수 분포와 실측 비용으로 시간을 가중 추정합니다. 신규/캐시·재시도·준비·출력 시간을 포함하고 불확실성을 표시합니다. 원본 행·논리 카드·선택형 질문·HTTP 요청 수를 따로 제시합니다. 질문 수 감소율은 실측 시간 단축률이 아닙니다. 경로·관계 검사의 비용은 기본 카드 검사와 별도로 보고합니다.

## 7. 시작 조건과 결과물

실행 전에 입력/프로파일/코드 해시, 행·카드·질문 목록, 관계 원장 버전, 연결표, 전 행 복원 결과, 미해결 공백, 토큰 검사, 캐시 규칙, 실측 시간 추정이 담긴 설계 기록을 저장합니다. 계약이 바뀌면 옛 범위를 새 카드·질문에 연결하고 의미 변화를 설명합니다. 옛 쌍 연결 보존이 모든 옛 답의 재현을 뜻하지 않습니다.

완료에는 모든 원본 관측의 연결, 모든 선언 질문의 실제 모델 응답 또는 정확히 일치하는 검증 캐시, 필수 통합 완료, 설명 없는 누락·실패 0이 필요합니다. 계획상 포함·모델 검사·과학적 타당성을 구분합니다.

기본 결과는 `candidates.csv`입니다. 후보–원본 연결표, 배경을 포함한 전체 검사, 미확정 검토 큐, 고정 입력/프로파일/코드, 원시 응답과 검증을 함께 제공합니다. 같은 질문의 반복 검사가 후보 수를 부풀리지 않아야 합니다. 사후 가설·프로토콜 질문, 관측·제안 기전을 구분합니다. 환자 공통 패턴은 식별 가능한 짝지은 환자 근거로 판단하며 DEG 중복만으로 세포 소통·인과·대사 흐름을 주장하지 않습니다.
